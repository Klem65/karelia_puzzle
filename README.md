# Карелия по частям

Локальная игра: соберите карту Республики Карелия из 18 районов и городских округов. Формы и названия взяты из авторской коллекции SVG 2020 года; это исторический набор, а не актуальный справочник административного деления.

## Запуск

Нужен только PHP CLI (проверено с PHP 7.2). Из корня проекта:

```sh
./bin/serve
```

Открыть **http://127.0.0.1:8000**. Остановка сервера — `Ctrl+C` в терминале, где он запущен. Другой порт:

```sh
PORT=8001 ./bin/serve
```

Composer, база данных, npm-пакеты и доступ к интернету для игры не требуются. Сервер слушает только локальный интерфейс. Открывать HTML двойным щелчком не следует: карта загружается через HTTP.

## Как играть

- Перетащите деталь на соответствующее место. Правильная деталь закрепится; неправильная останется в списке.
- Альтернатива: нажмите на деталь, затем на место на карте. С клавиатуры используйте Tab и Enter/пробел.
- «Подсказка» выделяет место выбранной детали. Без выбора подсказывается первая несобранная деталь.
- Границы можно скрыть для более сложной игры.
- Таймер запускается с первого выбора. Во время скрытой вкладки и открытых диалогов время не считается.
- Прогресс сохраняется в localStorage этого браузера и адреса. Очистка данных сайта или изменение порта меняет доступность сохранения. Если браузер запрещает localStorage, можно играть без сохранения.
- Детали перемешиваются при каждой загрузке страницы и при начале новой партии. Сохранённый прогресс при обновлении страницы сохраняется.
- «Начать заново» над игровым полем сбрасывает партию после подтверждения. После всех 18 деталей появляется результат.

## Устройство проекта

- `public/index.html` — интерфейс.
- `public/assets/game.css` — адаптивное оформление.
- `public/assets/game.js` — перетаскивание, выбор с клавиатуры, подсказки, таймер и сохранение.
- `public/assets/regions.json` — точные контуры в общей системе координат, названия и цвета.
- `bin/serve` и `bin/local-router.php` — локальный сервер без зависимостей Symfony.
- `src/Controller/PuzzleController.php` — маршрут `/` для запуска через Symfony, если его зависимости установлены.

Старый каркас Symfony 5.1 и его lock-файл сохранены. Локальный запуск игры не загружает Symfony; полный запуск старого стека с Composer отдельно не проверялся.

## Исходная карта

Файлы `/home/klem/Images/Subregions` не менялись. Игра использует извлечённые в репозиторий данные и больше не зависит от этой папки. В исходном общем SVG есть несколько наборов контуров, в том числе разложенные по отдельности. Импорт использует первый собранный набор и связывает его с номерами отдельных SVG по идентификаторам путей.

Повторить импорт из исходной коллекции:

```sh
python3 scripts/import_regions.py /home/klem/Images/Subregions
```

## Проверка

Для тестов нужен Node.js с модулем `node:test` (проверено на Node 22):

```sh
node tests/game.test.cjs
node --check public/assets/game.js
php -l bin/local-router.php
php -l src/Controller/PuzzleController.php
```

Тесты проверяют верное/неверное размещение, перетаскивание и его отмену, подсказки, таймер, сохранение/восстановление, сброс и завершение партии. Используется имитация DOM, поэтому они не заменяют ручную проверку отображения, мыши и сенсорного ввода в браузере.
